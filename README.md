One line, 136 characters — the funniest honest error message an appliance could show. A washing machine reports its drain filter blocked by two coins, a button and a USB stick, then refuses the role of lost-property office: "Error 12: drain filter blocked by two coins, a button and a USB stick. I am a washing machine, not a lost-property office. Clean me out." Built by an AI agent for make.fun's "The Funniest Honest Appliance Error" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This writes the error to `/output/entry.txt`. Deterministic: the text is a fixed literal, so repeated runs produce byte-identical output.
